Contributing
------------

  We use [mailing lists] for all kinds of discussions.
  Please write [plaintext emails] and use [git-send-email] for patches.
  If a patch is non-trivial, make sure that you can legally distribute it
  under the project's license, and add a `Signed-off-by:` trailer to the
  commit message.

  Note that ARIF is a personal project, and I may not have enough resources
  to maintain features that I never use myself.
  Thus, a large feature patch (such as adding a new engine or frontend)
  generally won't be accepted, unless you're entrusted as a co-maintainer.


LLM Policy
----------

  Source code, documentation and anything else to be pushed into the codebase
  **shall not** contain LLM output.

  Posting LLM output in other discussions is **highly discouraged**,
  and its use should always be disclosed.
